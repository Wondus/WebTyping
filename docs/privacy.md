# WebTyping Privacy Policy

Effective date: July 29, 2026

WebTyping is a browser extension that turns text from the currently active webpage into a typing exercise.

## Data processing

WebTyping processes webpage text and typing input locally on the user's device. This processing occurs only after the user explicitly activates the extension.

WebTyping does not collect, transmit, sell, share, or provide the developer or any third party with:

- webpage content;
- browsing history or visited URLs;
- typing input;
- typing results or statistics;
- personal information; or
- analytics or diagnostic information.

## Local storage

WebTyping stores extension preferences locally using the browser's extension storage. These preferences include settings such as font size, case sensitivity, punctuation handling, and emoji handling.

Article text and typing-session statistics are held temporarily in memory. They are not retained by the developer or transmitted outside the browser.

## Permissions

WebTyping uses the following browser permissions:

- `activeTab` to access the current page after the user activates WebTyping;
- `scripting` to display the typing interface on that page; and
- `storage` to save extension preferences locally.

## Network access and third parties

WebTyping does not make external network requests, use analytics, display advertising, or share data with third parties.

## Changes

This policy will be updated if WebTyping's data-handling behavior changes. The effective date above indicates the latest revision.

## Contact

For privacy questions, [open an issue in the WebTyping repository](https://github.com/Wondus/WebTyping/issues).
